# ASMI Vernier Go Direct Mount (Cub)

Two-part mount (base + cover) for attaching a Vernier Go Direct force
sensor to the **Cub** gantry for
[ASMI](https://github.com/BU-KABlab/ASMI_new)-style indentation work.

A newer revision (REV. 3) sized for the CubXL lives in
[`../../../cubxl/instrument_mounts/asmi/`](../../../cubxl/instrument_mounts/asmi/).

## Files

| File | Purpose |
| --- | --- |
| `Vernier Go Direct Mount (Base)_REV. 0 (2).step` | Base half of the sensor mount. |
| `Vernier Go Direct Mount (Cover)_REV. 0 (1).step` | Cover that clamps the sensor into the base. |

## Compatibility

- Gantry: **Cub** (SainSmart PROVER 3030)
- Sensor: Vernier Go Direct force sensor
